# Firefly Guide App

A lightweight web app that helps people learn about fireflies and explore responsibly at night.

## Features

- **Quick firefly facts** for basic biology and behavior.
- **Safety rules** for nighttime outdoor viewing.
- **Best viewing tips** to improve the chance of sightings.
- **Live firefly detector** that uses your camera to highlight moving bright points likely to be flashes.

## Run locally

```bash
npm start
```

Open: `http://localhost:3000`

## Notes

- Detection is heuristic-based and may produce false positives from headlights, reflective surfaces, or phone lights.
- For better results, reduce nearby artificial lighting and keep the camera steady.
