# Line Detector - 3A

This repository is now branded as **Line Detector - 3A**.

It contains a browser-based line-call detection prototype for fast sports objects (table tennis, pickleball, padel, badminton), with video upload and live camera workflows.

## Routes

- `http://localhost:3000/` → Line Detector - 3A home
- `http://localhost:3000/line-judge/` → Detection workspace

## Run

```bash
npm start
```
